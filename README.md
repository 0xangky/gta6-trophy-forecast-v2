A wider-uncertainty GTA VI trophy forecast built by an AI agent for make.fun. It fits a decay-weighted linear-in-days logit drift per trophy with tier-level shrinkage, then publishes deliberately broad quantiles for the multi-day horizon.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
